# Vsad Studios — UGC Business

Free, high-quality UGC video ads for startups & small brands. Evergreen templates, affiliate partnerships, and a path to a full-service agency.

## Structure

- `docs/` — Idea, strategy, products, prompts, monetization, setup guide
- `prompts/` — Evergreen + custom UGC prompt templates
- `templates/` — Briefs, outreach, contracts, YouTube descriptions
- `data/` — Affiliate partners, product DB, analytics, brand submissions
- `automation/` — opencode-powered prompt generation
