# Videos

Final UGC ad templates live here. Each file is linked from its `seo/<name>.md` file and promoted via the YouTube video + pinned comment.

## Download

- Direct (raw file): `https://raw.githubusercontent.com/Vsad-Laboratories/UGC_Business/main/videos/<file>.mp4`
- GitHub page: open the file in this repo → "Download raw file"

## Naming

`videos/<product-slug>.mp4` — lowercase, hyphens, matches `seo/<name>.md` and `data/product-database.json`.

## Rebuilding a video file

The prompts used to generate each ad live in `prompts/custom/<name>.md`. Run them through your video tool (Google Flow, etc.) and drop the result back in this folder. For downloading reference videos of your own published ads, use Cobalt (cobalt.tools) or any free yt-dlp-based downloader — save here and commit.
